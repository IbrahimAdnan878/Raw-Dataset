# Raw Dataset

This repository contains the raw unified environmental dataset used in the paper:

A Containerised Cloud-Continuum Framework for Multi-Model Environmental Risk Forecasting and Mitigation Support in Iraqi Cities.

The dataset contains daily environmental records for Baghdad, Basra, Mosul, Erbil and Kirkuk.
It includes meteorological variables, air-quality indicators, drought-related fields, dust-related indicators and timestamp/city information before the cleaning and preprocessing stage.
